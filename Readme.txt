 🖼️ Image Gallery – CodeAlpha Internship

A modern and responsive Image Gallery built using HTML, CSS, and JavaScript as part of my CodeAlpha Front-End Development Internship.

The project allows users to browse images in a responsive gallery and open individual images in a full-screen lightbox with navigation controls.

📌 Features

 🖼️ Responsive image gallery
 🔍 Lightbox view for displaying large images
 ⬅️ Previous image navigation
 ➡️ Next image navigation
 ⌨️ Keyboard navigation

   `←` Left Arrow – Previous image

 💡 How It Works

 1. Image Gallery

Images are displayed in a responsive layout using HTML and CSS.

The gallery automatically adjusts to different screen sizes using CSS responsive techniques.

 2. Lightbox

When a user clicks on an image, the selected image opens in a larger view.

The lightbox provides a dedicated area for the image and navigation controls.

 3. Previous and Next Navigation

Users can navigate between images using the Previous and Next buttons.

The navigation buttons remain positioned beside the image instead of moving according to the image height.

 4. Keyboard Navigation

The gallery also supports keyboard controls:

| Key   | Action         |
| ----- | -------------- |
| `←`   | Previous image |
| `→`   | Next image     |
| `Esc` | Close lightbox |

 5. Responsive Design

The gallery is designed to work on:

 💻 Desktop
 💻 Laptop
 📱 Mobile
 📱 Tablet

The large images use `object-fit: contain` and maximum dimensions so that different image sizes can be displayed without overflowing the viewer.

 🎨 UI Design

The project uses a dark background with rounded image corners and smooth hover effects.

A cursive heading font is used to give the gallery a more attractive and creative appearance.
